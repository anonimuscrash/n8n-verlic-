VERLIC AGENT PANEL — INÍCIO RÁPIDO

1. Copie .env.example para .env
2. Troque APP_PASSWORD e JWT_SECRET
3. Para abrir sem n8n, mantenha N8N_MOCK_MODE=true
4. Rode:
   npm install
   npm run build
   npm start
5. Abra http://localhost:3000

Para conectar ao n8n:
- Preencha N8N_WEBHOOK_URL
- Preencha N8N_WEBHOOK_SECRET
- Altere N8N_MOCK_MODE=false
- Consulte docs/CONTRATO-N8N.md

O projeto também está pronto para Docker e Coolify.
